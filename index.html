O token de publicação tem curta duração e permissão apenas para o repositório instalado. Os arquivos da experiência precisam estar em um repositório público para abrir pelo celular.
PRIMEIROS PASSOS

Como publicar

  1. Entre com o GitHub. A sessão conecta o Studio ao repositório público instalado.
  2. Escolha o modo e envie o GLB. Marker Based acompanha uma imagem; Local Based posiciona por GPS.
  3. Prepare o marcador. Gere e carregue os descritores NFT da imagem escolhida.
  4. Publique e compartilhe. O modelo, o marcador e o manifesto são gravados no GitHub. Abra o link WebAR em outro celular.

A câmera e a localização exigem HTTPS. O GitHub App usa uma autorização curta, limitada ao repositório instalado.

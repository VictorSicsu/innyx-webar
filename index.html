PRIMEIROS PASSOS

Como publicar

  1. Escolha o modo. Marker Based acompanha uma imagem natural. Local Based posiciona o modelo em coordenadas GPS.
  2. Envie o GLB. Escolha uma animação e ajuste a escala na prévia 3D.
  3. Conecte o GitHub. Use um token fine-grained limitado ao repositório InnyxWebAR.
  4. Publique e compartilhe. O modelo, marcador e manifesto são gravados no repositório. Use o link da experiência para abrir a câmera em outro celular.

Marker Based sem borda preta usa os três descritores NFT gerados pelo gerador oficial do AR.js. A câmera e a localização exigem HTTPS.
